# Подбор вина

Streamlit-приложение оценивает вероятность хорошего вина. Модель уже обучена, при запуске обучение не выполняется.

## Запуск

Проверено с Python 3.12.13. Выполните команды из папки `wine_app`.

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

## Вкладки

«Одно вино» принимает 12 признаков. «Модельные метрики» показывает качество на тесте. «Пакетное предсказание» принимает CSV из `example.csv`. Последняя вкладка показывает коэффициенты модели. Ползунок слева меняет порог во всех вкладках.

Модель загружается через `st.cache_resource`, таблица и вероятности через `st.cache_data`. Поэтому слайдер не загружает модель и не пересчитывает вероятности заново.
